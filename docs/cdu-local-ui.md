# CDU 应用内课表与本地数据（2026-10-11）

## 使用方式

- 登录成功后自动串行同步个人资料、课表、成绩和考试。也可点击“同步教务到应用”重新更新；某一类失败保留已有数据。
- 重启后自动读取当前账户各类别的最新本地 JSON，不要求再次登录。学校认证状态仍如实显示为未验证；本地可读不代表学校会话有效。
- “导入文件”展开学号、学期和文件选择。CSV、HTML 或 XLSX 仍须先预览、确认再保存；保存后进入与在线同步相同的前端视图。
- 课表按源数据中的星期、节次排列，连续相同单元格合并为课程卡片；无星期的文件按课程清单展示，不推算时间。学校时间、周次、教师、地点和备注保留原文，完整安排和原始表格可以展开核对。
- 成绩保留完整已加载表格，学籍资料显示字段卡片；考试为空时只说明当前同步范围无记录，不扩大到其他批次。
- 学校窗口用于认证及必要的学期、周次、分页确认。后台缺表会显示失败提示，不自动弹出学校窗口；扫码等认证仍显示原生学校窗口。

## 设计依据（brand-spec）

沿用本仓库已存在的 UI，不引入新主题或依赖：

- 校徽：`apps/electron/src/renderer/assets/cdu-logo.svg`；其真实性与既有资产保持一致。
- 色彩：Tailwind 现有 `primary / card / muted / background / foreground` 语义变量及其透明度；跟随应用深浅主题。
- 字体：应用 `styles/globals.css` 现有字体栈。标题与正文保持现有字号等级。
- 间距：4px 基础单位，工具栏 8–12px、内容 16–24px；卡片圆角 `rounded-xl / rounded-2xl / rounded-3xl`，阴影 `shadow-sm`。
- 控件：现有 `@profer/ui` Button/Input/ConfirmDialog 与 Lucide 图标；鼠标、键盘和原生 details 折叠行为沿用项目。
- 本地内容优先显示。已有数据时连接表单折叠，避免账户卡占据课表主体空间。

## 数据流与验证

`getSavedData` → 当前账户 `CduStore.latest` → Jotai 数据集 → `CduDatasetView` → `CduScheduleView` / 学籍字段卡片 / 成绩表 / 考试空状态。恢复只扫描当前账户，按各类别获取时间选择最新数据；同批跨学期成绩优先保留更多可见行。清除缓存后防止尚未返回的旧恢复请求重新写入状态。

在隔离桌面实例重启后，学校状态为未连接，本地课表自动恢复并显示 19 个课程安排卡片，含源记录中的时间、周次、教师和地点。此数量指合并后的卡片，不是课程门数，也不代表任意指定周实际开课数。真实数据与截图仅保留在本机验收目录，不加入 Git。

新增 BDD 覆盖本人缓存隔离、跨学期最新恢复、课表合并及备注、无星期清单导入、应用内渲染不嵌入网页、考试空状态以及空网格等待课程填充。页面未加载的分页、学校筛选、其他平台与完整业务 API 不在本次验收范围内。

最终验证：全仓 3472 项测试通过，4 项 Windows 平台测试跳过，0 失败；9 包类型检查、主进程/Preload 构建及架构边界检查通过。缓存中损坏的空学期记录会跳过，不影响其余数据恢复。版本 Electron 0.15.144、shared 0.1.67，无新增第三方依赖。
