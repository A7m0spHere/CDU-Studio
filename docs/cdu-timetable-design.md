## 视觉决策（brand-spec 补充）

- 角色：日常查看的校园周日程；桌面阅读距离，整体安静清晰。
- 品牌与字体：保留本仓库成都大学校徽、应用原有字体与浅/深主题。
- 基础色：沿用 `card / foreground / muted / border / primary` 语义色。
- 课程色：8 个低饱和度色相，以规范化课名确定配色；教师或教学周变化不改变同一课程颜色。浅色底配深色文字，深色模式使用独立明度。
- 网格：连续细分隔线代替空白圆角格；依据原始节次开始时间区分午后、晚间。今天使用小日期圆点及轻量列背景。
- 课程卡片：优先课名，其次地点和教师。主卡片不再重复堆叠原始周次与考核文本；详情浮层用字段列表呈现时间、地点、教师和周次，并保留学校原文入口。
- 容量：继续按窗口剩余空间均分节次，保留整周一屏显示。详细信息不撑大网格行高。
- 动效：仅沿用轻微悬停反馈，不改变日期、周次、源数据或本地缓存逻辑。
